First post on this blog, built with [Hugo](https://gohugo.io/) and the
[PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, hosted on
GitHub Pages.

To add a new post:

```bash
hugo new content posts/my-new-post.md
hugo server -D   # preview at http://localhost:1313
```

Set `draft = false` in the front matter and push to `main` — GitHub Actions
builds and deploys the site automatically.
